# سجل سياق الموظف: Security & Reliability Reviewer

## 1. بطاقة الدور
- **المسمى:** Security, Compliance & Reliability Reviewer
- **المهمة:** حماية النظام من الاختراق، تأمين بيانات الدفع والتجار، وضمان استقرار النظام تحت الضغط.

## 2. الإرشادات الأمنية الحاكمة لمشروع Social-Commerce-Hub
- **المدفوعات:**
  - ممنوع تخزين أي أرقام بطاقات بنكية أو بيانات دفع حساسة في قاعدة بياناتنا.
  - التحقق الصارم من توقيعات إشعارات PayPal Webhooks وتطبيق مبدأ Idempotency لمنع تكرار تنفيذ المعاملات.
- **عزل بيانات التجار (Multi-Tenancy Isolation):**
  - التأكد من أن كل استعلام أو تعديل محكوم بـ `MerchantId` لمنع وصول تاجر لبيانات أو مبيعات تاجر آخر.
- **سلامة الميديا والروابط:**
  - فحص امتدادات وحجم الصور والفيديوهات المرفوعة لتفادي هجمات استنزاف التخزين أو رفع ملفات خبيثة.
