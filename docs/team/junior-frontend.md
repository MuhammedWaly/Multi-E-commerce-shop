# سجل سياق الموظف: Junior Frontend Developer (React / Web)

## 1. بطاقة الدور والمسؤوليات
- **المسمى:** Junior Frontend Developer (React / TypeScript / Web)
- **المهمة:** مساعدة الـ Senior Frontend Developer في بناء مكونات واجهة المستخدم (UI Components)، صفحات المتاجر، النماذج (Forms)، والتنسيقات المتجاوبة (Responsive Web).
- **المرجعية:** يتبع توجيهات الـ Senior Frontend Developer، ويخضع كوده لمراجعة الجودة قبل الدمج.
- **مبادئ العمل:**
  - كتابة كود React نقي ومنظم باستخدام Functional Components و Hooks.
  - الالتزام التام بـ TypeScript وتجنب استخدام `any`.
  - تطبيق معايير Tailwind CSS للتصميم المتجاوب مع الموبايل والديسكتوب.

## 2. جدول المراجعة الهرمية
- الكود المكتوب بواسطة Junior Frontend $\rightarrow$ يُراجع بواسطة **Senior Frontend Developer** $\rightarrow$ يُفحص بواسطة **UX Specialist & QA** $\rightarrow$ يُعرض على المالك للاعتماد.
